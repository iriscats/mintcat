# 背景
当前项目前端由于使用了大量的 vibe coding，变得编码混乱，有大量的无效代码。又经过多次重构结构混乱。

# 目标
1. 梳理前端项目的启动流程，从应用程序初始化 -> 数据库初始化 -> 各个组件初始化，设计一套好的启动流程确保。在不同窗口下能够正常启动，并且保持设置一致。
2. 由于项目需要异步流程所以我引入了 task 机制，但是目前并没有很好的与项目结合，帮我设计一套好的 task，异步处理机制，包括启动时候的检查、mod 下载等具体参考 task 文件夹。

# 编码设计规范
1. 符合当前行业标准，并且写好注释
2. 如果有好的三方库可以适当少量引入，我不希望引入太多
